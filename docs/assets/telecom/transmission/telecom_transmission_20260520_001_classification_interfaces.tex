\section*{Préparation TC PQ CFC IELE,PELE}
\begin{questions}
\question 
Vous devez établir le descriptif technique pour le câblage multimédia d'une salle de conférence connectée. Afin de garantir la compatibilité des équipements avec l'infrastructure prévue, vous devez classer les technologies suivantes selon leur support physique de transmission~:
\begin{itemize}
	\item HDMI
	\item Bluetooth
	\item NFC
	\item USB
	\item 1GBaseT
	\item POF (Plastic Optical Fiber)
\end{itemize}

*Consultez votre cours de télécommunication sur les supports de transmission (chapitres 3.4.1) et effectuez une recherche sur les sites des constructeurs pour identifier les distances maximales actuelles autorisées pour chaque interface selon les DIT.*

\begin{solution}
	\textbf{Analyse des supports :}
	\begin{itemize}
		\item \textbf{HDMI} : Filaire cuivre (Utilisé pour la transmission audio/vidéo haute définition sur de courtes distances).
		\item \textbf{Bluetooth} : Sans fil (Protocole WPAN pour l'échange de données à courte portée).
		\item \textbf{NFC} : Sans fil (Communication en champ proche par induction électromagnétique).
		\item \textbf{USB} : Filaire cuivre (Standard de connexion série pour périphériques informatiques).
		\item \textbf{1GBaseT} : Filaire cuivre (Standard Ethernet pour réseaux LAN sur paires torsadées).
		\item \textbf{POF} : Optique (Fibre optique plastique utilisée pour les réseaux domestiques ou industriels).
	\end{itemize}
	\end{solution}
\end{questions}
